# Rover Control System

This repository contains the complete codebase for a rover control setup — one running **onboard** the rover (Jetson Nano) and the other on the **base station** (control computer).

## Project Structure

├── base_station/     
├── onboard/                
└── README.md

**base_station** contains GUI for Rover Control (via serial communication) 
<br> 
**onboard** contains Onboard programs running on Jetson Nano performing mutliple tasks.
