# Rover Control System

This repository contains the complete codebase for a rover control setup — one running **onboard** the rover (Jetson Nano) and the other on the **base station** (control computer).

## Project Structure
.
├── base_station/           # Graphical User Interface for Rover Control (via serial communication) 
├── onboard/                # Onboard programs running on Jetson Nano.
└── README.md
